Oakley's framing, borrowed from a pile of neuroscience and simplified almost to a metaphor: there is a mode where attention is narrow and you work along established paths, and a mode where attention is loose and connections form between things that were not adjacent. You cannot be in both at once.

Focused mode is where the actual work gets done, and it is also where you get stuck. Being stuck is usually a sign that the problem has been framed in a way that makes the solution unreachable from where you are, and no amount of additional focus reframes it — focus is precisely the state that keeps you inside the current frame.

Diffuse mode is what reframes. The walk, the shower, the fifteen minutes before sleep. It is not rest; it is a different processing regime, and it only runs on problems you loaded in beforehand. This is the key operational point: diffuse mode has nothing to work with unless focused mode has recently supplied it.

So the practice is alternation with a load-then-release rhythm. Work hard on the problem until stuck, then genuinely leave — not a screen, not another task at the same intensity. Come back.

The connection to memory is that alternation forces spacing, and spacing is where consolidation happens, which is one more instance of [[Desirable Difficulties]] paying out later rather than now. It also builds structure: the connections that form in the loose state are how [[Chunking]] happens, since chunks are made of links between things previously held apart.

Practically this is why [[Interleaving Beats Blocking]] does not just improve discrimination but reduces the grinding, and why a stall that lasts days is usually a signal to change methods rather than to try harder — the pattern in [[Plateaus and Breakthroughs]].
