Monthly hygiene pass. Ninety minutes, and the report was more interesting than usual.

**Nineteen stubs.** Notes I created as link targets and never wrote. Most are fine — a stub is a promise, not a failure — but four have been sitting there since last summer, which means they are not promises, they are decoration. Deleted three. The fourth I actually wrote, which took eleven minutes and I have no idea why it waited nine months.

**Two notes that should be one.** The suggestion report flagged them at the top of the list: same source, same three tags, no link either way. Reading them side by side they are the same argument written twice, four months apart, with the second one slightly better. Merged. That is the case [[When to Split a Note]] handles from the other direction — the same criterion, run backwards, tells you when to join.

- [x] Orphan report: 9 flagged, 5 acted on
- [x] Stubs: 19 found, 3 deleted, 1 written
- [x] One merge
- [ ] Rewrite the four "see also" link contexts I found; they are useless in the panel

The rest of the session was me tuning the hygiene tooling, again. This is the third month running that I have improved the report rather than acted on it, which is the exact failure named in [[Against the Perfect System]] — the system is a project I can always work on, and working on it feels like maintenance while being avoidance. [[The Weekly Note Hygiene Review]] is supposed to take twenty minutes; if it takes ninety, most of that ninety is not hygiene.

Two conventions added to [[Vault Conventions]], both about link context rather than structure: no bare "see also", and a link in a heading does not count.

The one genuinely good outcome is that the merged note is better than either parent and I would never have found the pair by browsing. Structural noticing beats folder tidying, which I keep having to relearn — [[Links Over Folders]] is the note, and April 30th is the third time this year the evidence has arrived unsolicited.

Also: I have not published anything since February. [[Writing in Public]] is the forcing function that makes hygiene matter, and without it this is gardening for its own sake.
