Restructured this week's practice sessions into interleaved sets — mixed problem types in a single sitting instead of thirty of the same kind. It felt considerably worse than last week. Slower, clumsier, more errors, and a distinct sense of never getting into rhythm.

Which is, per every source I have read on this, the point. [[Interleaving Beats Blocking]] predicts exactly this: blocked practice produces fluent sessions and poor retention, because within a block you stop deciding *which* method applies and start executing the one you already loaded. Interleaving forces the selection step, which is the step that actually transfers.

Barbara Oakley's framing in *A Mind for Numbers* is the one that keeps me honest — the discomfort is not a side effect to be tolerated, it is the mechanism. [[Desirable Difficulties]] says the same thing more formally, and the whole family of results only makes sense once you accept that performance during practice and learning from practice come apart.

What I noticed concretely:

- [x] Six sessions, mixed sets, roughly 40% more time per problem
- [x] Error rate up sharply on the first two days, flat by the fifth
- [ ] Retest the week-one material next Thursday and see whether any of this was real
- [ ] Stop tracking within-session accuracy; it is measuring the wrong thing

That last one matters. Within-session accuracy is precisely the metric that rewards blocking, and if I keep watching it I will drift back within a fortnight.

The thing I underestimated is how much of the difficulty is a chunking problem rather than a memory problem — [[Chunking]] describes assembling a method into a single retrievable unit, and interleaving is hard partly because my chunks are still loose enough that switching between them costs real effort. Presumably that gets cheaper.

Delayed retest is the only honest measurement available, which is [[The Forgetting Curve]] as an experimental design rather than a fact. And the retest itself is [[Retrieval Practice Beats Review]] — the measurement is also the intervention, which is convenient and slightly suspicious.
