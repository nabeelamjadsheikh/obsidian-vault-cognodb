Forty minutes, three people, no slides. Ran it against the questions in [[Project Postmortem Template]] rather than the usual went-well/went-badly columns, which produced noticeably less flattering answers.

## Shipped

Import for the second format. The backlink panel with edge annotations, which is the feature everyone actually uses. Andrew's rewrite of the neighbourhood traversal, now roughly four times faster and considerably easier to read.

## Stalled

The link view. It has been "nearly done" for six weeks, which is the classic symptom — it is not nearly done, it is unbounded, and nobody has said so out loud. Keiko named it in the room: we have never written down what question the view answers, so there is no state in which it is finished. That is scope behaving exactly as described in [[Scope Is a Stock]], with an inflow and no defined outflow.

Onboarding polish also stalled, for the better reason that we were waiting on a real decision from [[Lantern — Open Questions]] and correctly refused to guess.

## The one process change we are keeping

Every work item now names the smallest version of itself that a real person could use, and that version is what gets scheduled. Not a spike, not a foundation — a thin vertical thing that works end to end. This is the discipline in [[Ship the Smallest Real Slice]] and we have been sloppy about it since January.

We are keeping exactly one change, not five. Five process changes is how a retro produces nothing.
